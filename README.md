# 기윤실교사모임 앱

> 교육의 길이 되는 기윤실교사모임: 함께 기쁘게 용기 있게

휴대폰 홈 화면에 설치해서 쓰는 웹앱입니다.
**구글 시트 링크 하나만 연결하면** 시트에 적은 내용이 앱에 자동으로 나타납니다. 서버·DB·별도 프로그램이 필요 없고 무료입니다.

```
 구글 시트 (편집은 여기서)  ──링크──▶  앱 (누구나 보기)
```

| 앱 메뉴 | 내용이 오는 곳 |
|---|---|
| 📅 캘린더 | 시트 `캘린더` 탭 |
| 🙏 기도문 | 시트 `기도문` 탭 |
| 📰 소식지 | 시트 `소식지` 탭 |
| 💚 후원자 | 시트 `후원자` 탭 |
| 📷 사진 | 시트 `사진` 탭 (드라이브 사진 링크) |
| 🌿 소개 / 회원가입 안내 | `js/content.js` (자주 안 바뀌는 내용) |

## 시트 만들고 연결하기 (10분)

### 1. 양식으로 시트 만들기
1. 이 저장소의 [`template/기윤실교사모임_시트_양식.xlsx`](template/) 를 내려받습니다.
2. https://sheets.new 에서 새 시트를 열고 **파일 → 가져오기 → 업로드** 로 양식 파일을 올린 뒤
   **스프레드시트 바꾸기** 를 고릅니다. (`안내`, `캘린더`, `기도문`, `소식지`, `후원자`, `사진` 탭이 생깁니다)
3. 시트 이름을 `기윤실교사모임 앱` 정도로 바꿉니다.

> 탭 이름과 1행 머리글(초록색)은 바꾸지 마세요. 앱이 이 이름으로 내용을 찾습니다.
> 날짜는 `2026-10-10`, 시간은 `19:30` 처럼 적습니다.

### 2. 공유 설정
- **일반 액세스: 링크가 있는 모든 사용자 → 뷰어** (앱이 내용을 읽으려면 꼭 필요)
- 편집할 분들은 **공유 → 사용자 추가 → 편집자** 로 넣습니다. 이것이 곧 "편집 권한"입니다.
- **캘린더만 고칠 사람**이 있다면: 다른 탭들을 **데이터 → 시트 및 범위 보호 → 권한 설정 → 이 범위를 수정할 수 있는 사용자 제한** 으로 관리자만 남겨 둡니다.

### 3. 앱에 링크 넣기
`js/config.js` 의 `SHEET_URL` 에 시트 주소를 붙여넣습니다.

```js
export const SHEET_URL = "https://docs.google.com/spreadsheets/d/xxxxxxxx/edit?usp=sharing";
```

앱 오른쪽 위 **✏️ 편집** 버튼을 누르면 이 시트가 열립니다. (편집 권한이 없는 사람에게는 보기만 됩니다)

### 4. 사진
사진은 두 가지 방법으로 올릴 수 있습니다.
- **앱에서 관리자가 바로 올리기 (추천)**: 아래 [관리자 사진 올리기 설정](#관리자-사진-올리기-설정)을 한 번 해 두면,
  앱 오른쪽 위 🔑 로 로그인 → 사진 메뉴 → **+ 사진 올리기** → 사진첩 이름 고르기로 끝납니다.
- **시트에 직접 링크 붙여넣기**: 드라이브에 올린 사진의 공유 링크를 `사진` 탭의 `사진 링크` 칸에 붙여넣습니다.
  (사진·폴더는 **링크가 있는 모든 사용자: 뷰어** 로 공유되어 있어야 앱에 보입니다)

`앨범` 칸이 같은 사진끼리 앱에서 **사진첩**으로 묶입니다. 사진 메뉴에는 사진첩 목록이 먼저 나오고, 누르면 그 사진첩의 사진만 보입니다. (앨범 칸이 빈 사진은 `기타 사진`)

### 5. 앱 주소 만들기 (GitHub Pages, 무료)
1. 이 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택합니다. (처음 한 번만)
2. 이후 `main` 브랜치에 변경이 올라올 때마다 자동으로 배포됩니다. (**Actions** 탭 → `앱 배포` 에서 진행 상황 확인, 수동 실행도 가능)
3. 1~2분 뒤 `https://violetwizard-lim.github.io/eduhope/` 로 접속됩니다.
4. 휴대폰에서 열고 **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

## 알아 둘 점

- **반영 속도**: 시트를 고치면 앱을 다시 열거나 ↻ 를 누를 때 반영됩니다. 앱은 마지막 내용을 기억해 두었다가 열자마자 보여주고, 뒤에서 최신 내용을 받아옵니다.
- **공개 범위**: 시트는 링크가 있는 누구나 볼 수 있습니다. 후원자 명단을 공개하기 어렵다면 `후원자` 탭을 비우거나 지우세요.
- **넘겨드리기**: 시트를 만든 사람이 주인입니다. 단체에 넘길 때는 시트 **공유 → 받을 분을 편집자로 추가 → 권한 메뉴 → 소유권 이전**. 사진 폴더도 같은 방법으로 넘깁니다. 링크는 그대로라 앱은 고칠 필요가 없습니다.

## 미리보기

`SHEET_URL` 이 비어 있으면 예시 내용으로 동작합니다. 🔑 에서 `admin` / `admin` 으로 로그인하면 사진 올리기도 체험할 수 있습니다.

```bash
python3 -m http.server 8000      # 브라우저에서 http://localhost:8000
```

## 관리자 사진 올리기 설정

앱에서 관리자가 사진을 바로 올리려면, 비밀번호를 확인하고 드라이브에 대신 저장해 주는 작은 프로그램(Apps Script)을 시트에 한 번 넣어야 합니다.
**시트 주인이 한 번만** 하면 되고, 코드나 주소를 고칠 일은 없습니다. (약 5분)

1. **붙여넣기**: 시트에서 **확장 프로그램 → Apps Script** → 기존 내용을 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣고 **저장(💾)**
2. **설정 시작**: 시트 탭으로 돌아가 **새로고침** → 위쪽에 생긴 메뉴 **📷 기윤실 앱 → ① 설정 시작**
   - 권한 요청이 나오면 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**
     (직접 만든 스크립트라 구글이 따로 검사하지 않았다는 뜻입니다. 시트 주인에게 이번 한 번만 나옵니다)
   - 팝업에 **관리자 아이디·비밀번호**가 나옵니다. 꼭 적어 두세요.
   - 드라이브에 `기윤실교사모임 사진` 폴더가 자동으로 만들어집니다.
3. **배포**: 팝업 안내대로 Apps Script 화면에서 **배포 → 새 배포 → ⚙ 웹 앱** → 실행 계정 **나** / 액세스 **모든 사용자** → **배포**
4. **연결**: 배포가 끝나면 나오는 **웹 앱 URL** 아래 **복사** → 시트로 돌아와 **📷 기윤실 앱 → ② 앱과 연결** → 주소 붙여넣기 → 끝!
   - 웹 앱 URL 은 나중에도 **배포 → 배포 관리** 에서 복사할 수 있습니다.
   - 시트 `설정` 탭에 사진 올리기 주소가 적히고, 앱이 그 주소를 읽어 갑니다.
   - 앱을 껐다 켜거나 ↻ 를 누르면 오른쪽 위에 🔑 버튼이 나타납니다.

### 관리자 추가·비밀번호 바꾸기
시트 메뉴 **📷 기윤실 앱 → 관리자 추가·비밀번호 변경**
- 아이디를 입력하면 새 관리자 추가, 이미 있는 아이디면 비밀번호 변경
- 비밀번호를 비워 두고 확인을 누르면 그 관리자 삭제 (바로 올리기·삭제를 못 하게 됨)

> 시트는 링크가 있는 누구나 볼 수 있기 때문에, 비밀번호는 시트가 아니라 스크립트 속성에 보관합니다.
> 로그인은 6시간 동안 유지되고, 비밀번호를 10번 틀리면 15분 동안 막힙니다.

### 올리면 어떻게 되나요?
- 사진은 휴대폰에서 자동으로 줄여서(긴 쪽 1600px) 보냅니다.
- 드라이브 `기윤실교사모임 사진/사진첩이름/` 폴더에 저장되고, 시트 `사진` 탭에 한 줄이 추가됩니다.
- 앱에서 사진을 크게 볼 때 **삭제**를 누르면 시트 줄이 지워지고 드라이브 파일은 휴지통으로 갑니다.
- `Code.gs` 를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (주소는 그대로)
- 단체에 시트를 넘길 때는 넘겨받은 분이 ① 설정 시작 → 배포 → ② 앱과 연결을 한 번 다시 하면 됩니다.

## 파일 구성

```
index.html             화면 틀, 하단 탭
css/style.css          디자인 (세이지 그린 + 미색 배경, 다크모드 지원)
js/app.js              화면
js/data.js             시트 읽기, 관리자 로그인·사진 올리기 (+ 미리보기)
js/content.js          소개·회원가입 안내 등 고정 내용
js/config.js           시트 링크
template/              시트 양식 (xlsx)
apps-script/Code.gs    관리자 사진 올리기용 스크립트 (시트에 붙여넣음)
sw.js, manifest.webmanifest  홈 화면 설치 / 오프라인
```
