# 기윤실교사모임 앱

> 교육의 길이 되는 기윤실교사모임: 함께 기쁘게 용기 있게

휴대폰 홈 화면에 설치해서 쓸 수 있는 웹앱(PWA)입니다.

| 메뉴 | 누가 볼 수 있나 | 누가 고칠 수 있나 |
|---|---|---|
| 📅 캘린더 | 누구나 | **일정 담당**, 편집자, 관리자 |
| 📷 사진 | 누구나 | 편집자, 관리자 |
| 🙏 기도문 | 누구나 | 편집자, 관리자 |
| 📰 소식지 | 누구나 | 관리자 |
| 💚 후원자 명단 | 회원·편집자·관리자 | 관리자 |
| 🌿 소개 / 회원가입 안내 | 누구나 | 코드(`js/content.js`)에서 수정 |
| 🔑 권한 관리 | 관리자 | 관리자 |

## 로그인과 권한

- **아이디/비밀번호**: 관리자가 Firebase 콘솔에서 계정을 만들어 나눠 줍니다. 아무나 가입할 수 없습니다.
  - 예) `admin` (관리자), `calendar` (일정 담당 — 캘린더만 편집)
- **구글 로그인**: 개인 구글 계정으로 들어오고, 관리자가 그 이메일에 역할을 줍니다.
- 등록되지 않은 사람은 보기만 가능합니다.
- 일정·사진 등을 누가 마지막으로 고쳤는지 아이디와 시간이 남습니다.

권한 검사는 화면이 아니라 **서버(Firestore 보안 규칙, `firestore.rules`)** 에서 합니다.
화면을 조작해도 권한이 없으면 저장되지 않습니다.

## 바로 체험해 보기 (데모 모드)

`js/firebase-config.js` 가 비어 있으면 데모 모드로 동작하고, 데이터는 그 브라우저에만 저장됩니다.
아이디 `admin` / `editor` / `calendar` / `member` / `guest` (비밀번호는 아무거나)로 권한 차이를 볼 수 있습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 실제 운영하기 — Firebase 만들기 (약 15분, 무료)

Firebase 는 구글이 제공하는 서비스로 **로그인 + 데이터베이스 + 앱 주소(호스팅)** 를 한 번에 해결해 줍니다.
따로 서버나 DB 를 만들 필요가 없습니다. 이 규모의 모임이면 무료 요금제(Spark) 안에서 충분합니다.
사진도 앱이 자동으로 줄여서 DB 에 저장하므로 유료인 Storage 는 쓰지 않습니다.

> **누구 계정으로 만들까?** 단체 공용 구글 계정(예: 모임용 gmail)으로 만드는 것을 권장합니다.
> 개인 계정으로 만들었다면 아래 [인수인계](#인수인계-단체에-넘겨드리기)대로 단체 계정을 소유자로 추가하면 됩니다.

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: `eduhope`, 애널리틱스는 꺼도 됨)
2. **빌드 → Authentication → 시작하기**
   - **로그인 방법** 탭: **이메일/비밀번호** 사용 설정, **Google** 사용 설정
   - **설정** 탭 → **사용자 작업** → **생성(가입) 사용 설정** 체크 해제 ← 아무나 계정을 만들지 못하게 하는 설정
     (이 메뉴가 안 보여도 괜찮습니다. 아무나 만든 계정은 역할이 없어 보기만 가능합니다.
     다만 **계정을 먼저 만든 뒤에 역할을 주는 순서**는 꼭 지켜 주세요.)
3. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`, **프로덕션 모드**로 시작
4. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(</>) 앱 추가**
   - 나오는 `firebaseConfig` 값을 `js/firebase-config.js` 에 붙여넣기
5. **아이디 계정 만들기**: Authentication → **사용자** 탭 → **사용자 추가**
   - 이메일 칸에 `아이디@eduhope.app` 형식으로 입력 (예: `admin@eduhope.app`, `calendar@eduhope.app`)
   - 실제 메일 주소가 아니어도 됩니다. 앱에서는 `admin`, `calendar` 처럼 아이디만 입력하면 됩니다.
6. **첫 관리자 지정**: Firestore → **컬렉션 시작**
   - 컬렉션 ID `roles` / 문서 ID `admin@eduhope.app` / 필드 `role` (string) = `admin`
   - 이후 다른 계정의 역할은 앱의 **권한** 화면에서 줄 수 있습니다. (아이디 `calendar` → 일정 담당)
7. 보안 규칙과 앱 배포 (컴퓨터에 Node.js 필요):
   ```bash
   npm i -g firebase-tools
   firebase login
   firebase use --add          # 위에서 만든 프로젝트 선택
   firebase deploy             # firestore.rules + 앱 배포
   ```
   배포 후 `https://<프로젝트ID>.web.app` 주소로 접속합니다.
   휴대폰에서 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

비밀번호 변경·분실 시: Authentication → 사용자 → 해당 계정 ⋮ → **비밀번호 재설정**(콘솔에서 새 비밀번호 지정)

## 인수인계 (단체에 넘겨드리기)

1. Firebase 콘솔 → **프로젝트 설정 → 사용자 및 권한 → 구성원 추가** → 단체(대표) 구글 계정을 **소유자(Owner)** 로 추가
2. 앱 안의 관리자 아이디/비밀번호(`admin`)를 전달하고, 받은 분이 콘솔에서 비밀번호를 바꾸도록 안내
3. 필요하면 일정 담당용 `calendar` 계정 비밀번호도 함께 전달
4. 넘겨받은 쪽에서 모든 것이 확인되면 만든 사람의 계정을 구성원에서 제거

## 내용 고치기

- 소개 문구, 지역모임/전문모임 목록, 연락처, 바로가기 링크: `js/content.js`
  - 바로가기 버튼은 `LINKS` 의 `url` 을 채우면 나타납니다. (환영 게시판·유튜브 주소는 아직 비어 있음)
  - 회원가입 안내 문구와 구글 폼/신청서 링크는 `JOIN` 에 있습니다.
- 역할별 권한을 바꾸려면 `js/store.js` 의 `PERMISSIONS` 와 `firestore.rules` 를 **함께** 고쳐야 합니다.

## 파일 구성

```
index.html            화면 틀, 하단 탭
css/style.css         디자인 (세이지 그린 + 미색 배경, 다크모드 지원)
js/app.js             화면 그리기, 편집 폼, 사진 줄이기, 로그인 창
js/store.js           데이터 저장 (Firebase 또는 데모) + 권한 표
js/content.js         소개 페이지 고정 내용
js/firebase-config.js Firebase 연결 설정
firestore.rules       서버 권한 규칙
sw.js, manifest.webmanifest  홈 화면 설치 / 오프라인
```
