# 기윤실교사모임 앱

> 교육의 길이 되는 기윤실교사모임: 함께 기쁘게 용기 있게

휴대폰 홈 화면에 설치해서 쓰는 웹앱입니다. 내용은 **구글 시트**에 저장되고, 사진은 **구글 드라이브 폴더**에 저장됩니다.
따로 서버나 DB 가 필요 없고 무료입니다.

| 메뉴 | 누구나 | 일정담당 (`calendar`) | 관리자 (`admin`) |
|---|---|---|---|
| 📅 캘린더 | 보기 | **추가·수정·삭제** | 추가·수정·삭제 |
| 📷 사진 | 보기 | 보기 | **올리기·삭제** |
| 🙏 기도문 | 보기 | 보기 | 추가·수정·삭제 |
| 📰 소식지 | 보기 | 보기 | 추가·수정·삭제 |
| 💚 후원자 명단 | 비밀번호 입력 시 보기 | 비밀번호 입력 시 보기 | 보기·편집 |
| 🌿 소개 / 회원가입 안내 | 보기 | — | `js/content.js` 에서 수정 |

## 어떻게 동작하나요?

```
 휴대폰 앱  ──보기/저장──▶  Apps Script(시트에 붙은 작은 프로그램)  ──▶  구글 시트 / 드라이브 사진 폴더
```

- 앱 오른쪽 위 **관리자** 버튼 → 아이디/비밀번호 로그인 → 바로 추가·수정·삭제. **시트에 자동 저장**됩니다.
- 시트를 직접 고쳐도 앱에 그대로 나타납니다. (시트에서 줄을 추가하면 끝의 `ID` 칸은 자동으로 채워집니다)
- 아이디/비밀번호는 시트의 **계정** 탭에서 관리합니다. 줄을 지우면 그 계정은 즉시 로그인이 풀립니다.
- 권한 검사는 앱이 아니라 Apps Script 가 합니다. 일정담당 계정으로는 기도문 등을 저장할 수 없습니다.
- 앱은 마지막으로 받은 내용을 기억해 두었다가 **열자마자 보여주고**, 뒤에서 최신 내용을 받아옵니다.

## 바로 체험 (미리보기)

`js/config.js` 의 `SCRIPT_URL` 이 비어 있으면 예시 내용으로 동작합니다.
- 관리자: `admin` / `admin`, 일정담당: `calendar` / `calendar`
- 후원자 명단 비밀번호: `1234`

```bash
python3 -m http.server 8000      # 브라우저에서 http://localhost:8000
```

## 실제로 연결하기 (약 15분)

> **어느 구글 계정으로?** 모임 공용 구글 계정으로 만드는 것을 권장합니다. 시트·스크립트·사진 폴더의 주인이 그 계정이 됩니다.
> 다른 계정으로 만들었다면 아래 [인수인계](#인수인계-단체에-넘겨드리기)를 참고하세요.

### 1. 구글 시트 만들기
1. https://sheets.new 로 새 시트를 만들고 이름을 `기윤실교사모임 앱` 으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 내용을 지우고 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣고 **저장(💾)**.
4. 위쪽 함수 목록에서 **`setup`** 을 고르고 **실행** → 권한 요청이 나오면 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**
   (내가 만든 스크립트라 구글이 따로 검사하지 않았다는 뜻입니다)
5. 시트로 돌아가면 **캘린더 / 기도문 / 소식지 / 후원자 / 계정 / 설정** 탭이 생겨 있습니다.
   - **계정** 탭에 `admin`, `calendar` 계정과 임시 비밀번호가 만들어져 있습니다. 원하는 비밀번호로 바꾸세요.
   - 계정 탭은 시트 주인만 고칠 수 있게 자동으로 보호됩니다.

### 2. 사진 폴더 만들기
1. 구글 드라이브에서 `기윤실교사모임 사진` 폴더를 만듭니다.
2. 폴더 **공유 → 일반 액세스: 링크가 있는 모든 사용자 (뷰어)** — 앱에서 사진이 보이려면 필요합니다.
3. 폴더 주소 `https://drive.google.com/drive/folders/XXXXXXXX` 의 `XXXXXXXX` 부분을 복사해
   시트 **설정** 탭의 `사진 폴더 ID` 옆 칸에 붙여넣습니다.
4. 앱에서 올린 사진은 이 폴더(앨범 이름을 쓰면 그 이름의 하위 폴더)에 저장됩니다.
   드라이브에서 직접 폴더에 사진을 넣어도 앱에 나타납니다.

### 3. 웹 앱으로 배포
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
2. 실행 계정: **나**, 액세스 권한이 있는 사용자: **모든 사용자** → **배포**
3. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사해
   `js/config.js` 의 `SCRIPT_URL` 에 붙여넣습니다. `SHEET_URL` 에는 시트 주소를 넣습니다 (관리자에게 "시트" 버튼으로 보임).

> `Code.gs` 를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (URL 은 그대로)

### 4. 앱 주소 만들기 (GitHub Pages, 무료)
1. 이 저장소 **Settings → Pages → Build and deployment**: Source `Deploy from a branch`, Branch `main` / `/ (root)` → Save
2. 1~2분 뒤 `https://<깃허브아이디>.github.io/eduhope/` 로 접속됩니다.
3. 휴대폰에서 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

### 후원자 명단 공개 범위
- 시트 **설정** 탭의 `후원자 명단 비밀번호` 에 비밀번호를 넣으면, 그 비밀번호를 아는 사람만 앱에서 명단을 봅니다.
- 비워 두면 누구나 볼 수 있습니다. 관리자로 로그인하면 항상 보입니다.

## 인수인계 (단체에 넘겨드리기)

시트·스크립트·사진 폴더는 **만든 사람 계정이 주인**입니다. 넘겨드릴 때:

1. 시트 **공유 → 단체(대표) 계정을 편집자로 추가 → 그 사람 옆 권한 메뉴 → 소유권 이전**
2. 사진 폴더도 같은 방법으로 소유권 이전
3. 넘겨받은 분이 Apps Script 에서 **배포 → 새 배포** 를 한 번 다시 하고 (실행 계정이 넘겨받은 분이 되도록),
   새 웹 앱 URL 로 `js/config.js` 를 바꿉니다.
4. **계정** 탭에서 `admin` 비밀번호를 새로 바꿉니다.

가장 간단한 방법은 **처음부터 모임 공용 구글 계정으로 만드는 것**입니다. 그러면 비밀번호만 전달하면 됩니다.

## 내용 고치기

- 소개 문구, 지역모임/전문모임 목록, 연락처, 바로가기 링크, 회원가입 안내: `js/content.js`
- 역할별 권한을 바꾸려면 `apps-script/Code.gs` 의 `PERMS` 와 `js/data.js` 의 `PERMS` 를 **함께** 고치세요.

## 파일 구성

```
index.html             화면 틀, 하단 탭
css/style.css          디자인 (세이지 그린 + 미색 배경, 다크모드 지원)
js/app.js              화면, 편집 폼, 로그인, 사진 올리기
js/data.js             시트와 주고받기 (+ 미리보기 모드)
js/content.js          소개 페이지 고정 내용
js/config.js           시트 연결 주소
apps-script/Code.gs    구글 시트에 붙여넣는 스크립트 (읽기/쓰기/로그인/권한)
sw.js, manifest.webmanifest  홈 화면 설치 / 오프라인
```
