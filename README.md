# 기윤실교사모임 앱

> 교육의 길이 되는 기윤실교사모임: 함께 기쁘게 용기 있게

휴대폰 홈 화면에 설치해서 쓰는 웹앱입니다.
**구글 시트 링크 하나만 연결하면** 시트에 적은 내용이 앱에 자동으로 나타납니다. 서버·DB·별도 프로그램이 필요 없고 무료입니다.

```
 구글 시트 (편집은 여기서)  ──링크──▶  앱 (누구나 보기)
```

| 앱 메뉴 | 내용이 오는 곳 |
|---|---|
| 📅 캘린더 | 시트 `캘린더` 탭 |
| 🙏 기도문 | 시트 `기도문` 탭 |
| 📰 소식지 | 시트 `소식지` 탭 |
| 💚 후원자 | 시트 `후원자` 탭 |
| 📷 사진 | 시트 `사진` 탭 (드라이브 사진 링크) |
| 🌿 소개 / 회원가입 안내 | `js/content.js` (자주 안 바뀌는 내용) |

## 시트 만들고 연결하기 (10분)

### 1. 양식으로 시트 만들기
1. 이 저장소의 [`template/기윤실교사모임_시트_양식.xlsx`](template/) 를 내려받습니다.
2. https://sheets.new 에서 새 시트를 열고 **파일 → 가져오기 → 업로드** 로 양식 파일을 올린 뒤
   **스프레드시트 바꾸기** 를 고릅니다. (`안내`, `캘린더`, `기도문`, `소식지`, `후원자`, `사진` 탭이 생깁니다)
3. 시트 이름을 `기윤실교사모임 앱` 정도로 바꿉니다.

> 탭 이름과 1행 머리글(초록색)은 바꾸지 마세요. 앱이 이 이름으로 내용을 찾습니다.
> 날짜는 `2026-10-10`, 시간은 `19:30` 처럼 적습니다.

### 2. 공유 설정
- **일반 액세스: 링크가 있는 모든 사용자 → 뷰어** (앱이 내용을 읽으려면 꼭 필요)
- 편집할 분들은 **공유 → 사용자 추가 → 편집자** 로 넣습니다. 이것이 곧 "편집 권한"입니다.
- **캘린더만 고칠 사람**이 있다면: 다른 탭들을 **데이터 → 시트 및 범위 보호 → 권한 설정 → 이 범위를 수정할 수 있는 사용자 제한** 으로 관리자만 남겨 둡니다.

### 3. 앱에 링크 넣기
`js/config.js` 의 `SHEET_URL` 에 시트 주소를 붙여넣습니다.

```js
export const SHEET_URL = "https://docs.google.com/spreadsheets/d/xxxxxxxx/edit?usp=sharing";
```

앱 오른쪽 위 **✏️ 편집** 버튼을 누르면 이 시트가 열립니다. (편집 권한이 없는 사람에게는 보기만 됩니다)

### 4. 사진
1. 구글 드라이브에 사진 폴더를 만들고 **링크가 있는 모든 사용자: 뷰어** 로 공유합니다. (폴더 안 사진에 모두 적용됨)
2. 사진을 올린 뒤 사진의 **공유 → 링크 복사** 한 주소를 시트 `사진` 탭의 `사진 링크` 칸에 붙여넣습니다.
3. `앨범` 칸에 같은 이름을 쓰면 앱에서 앨범으로 묶여 보입니다.

### 5. 앱 주소 만들기 (GitHub Pages, 무료)
1. 이 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택합니다. (처음 한 번만)
2. 이후 `main` 브랜치에 변경이 올라올 때마다 자동으로 배포됩니다. (**Actions** 탭 → `앱 배포` 에서 진행 상황 확인, 수동 실행도 가능)
3. 1~2분 뒤 `https://violetwizard-lim.github.io/eduhope/` 로 접속됩니다.
4. 휴대폰에서 열고 **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

## 알아 둘 점

- **반영 속도**: 시트를 고치면 앱을 다시 열거나 ↻ 를 누를 때 반영됩니다. 앱은 마지막 내용을 기억해 두었다가 열자마자 보여주고, 뒤에서 최신 내용을 받아옵니다.
- **공개 범위**: 시트는 링크가 있는 누구나 볼 수 있습니다. 후원자 명단을 공개하기 어렵다면 `후원자` 탭을 비우거나 지우세요.
- **넘겨드리기**: 시트를 만든 사람이 주인입니다. 단체에 넘길 때는 시트 **공유 → 받을 분을 편집자로 추가 → 권한 메뉴 → 소유권 이전**. 사진 폴더도 같은 방법으로 넘깁니다. 링크는 그대로라 앱은 고칠 필요가 없습니다.

## 미리보기

`SHEET_URL` 이 비어 있으면 예시 내용으로 동작합니다.

```bash
python3 -m http.server 8000      # 브라우저에서 http://localhost:8000
```

## 선택: 앱 안에서 아이디/비밀번호로 편집하기

기본 방식에서는 편집을 구글 시트에서 합니다. 앱 화면 안에서 아이디/비밀번호로 로그인해 바로 편집하고
사진도 앱에서 올리고 싶다면, 시트에 [`apps-script/Code.gs`](apps-script/Code.gs) 를 설치하는 방법이 있습니다.
(시트 링크만으로는 앱이 안전하게 "쓰기"를 할 수 없어서, 비밀번호를 확인하고 대신 저장해 주는 작은 프로그램이 필요합니다)

설치 방법은 `Code.gs` 맨 위 주석에 있습니다. 설치하면 시트에 `계정`·`설정` 탭이 생기고,
배포한 웹 앱 주소를 `js/config.js` 의 `SCRIPT_URL` 에 넣으면 앱에 **관리자** 로그인 버튼이 나타납니다.
이 방식에서는 시트 탭 끝에 `ID`·`수정자`·`수정시각` 칸이 추가됩니다.

## 파일 구성

```
index.html             화면 틀, 하단 탭
css/style.css          디자인 (세이지 그린 + 미색 배경, 다크모드 지원)
js/app.js              화면
js/data.js             시트 읽기 (+ 선택 기능, 미리보기)
js/content.js          소개·회원가입 안내 등 고정 내용
js/config.js           시트 링크
template/              시트 양식 (xlsx)
apps-script/Code.gs    (선택) 앱 안 편집용 스크립트
sw.js, manifest.webmanifest  홈 화면 설치 / 오프라인
```
